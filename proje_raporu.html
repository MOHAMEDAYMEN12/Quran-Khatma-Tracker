1. Proje Özeti

Bu proje, Müslümanların Kur'an-ı Kerim okuma süreçlerini takip edebilmeleri için geliştirilmiş modern bir web uygulamasıdır. Kullanıcılar sisteme kayıt olarak kendi okuma ilerlemelerini takip edebilir, başka kişiler adına hatim başlatabilir ve doğrudan uygulama üzerinden Kur'an-ı Kerim okuyabilirler.

Uygulama, kullanıcı dostu arayüzü ve çift dil desteği (Türkçe ve Arapça) ile geniş bir kitleye hitap etmektedir. Proje, modern full-stack web teknolojileri olan React.js ve Node.js kullanılarak geliştirilmiştir.

📌 Proje Özellikleri
  • Kullanıcı kaydı ve oturum yönetimi (JWT tabanlı kimlik doğrulama)
  • Birden fazla hatim başlatma ve takip etme
  • Sure ve ayet bazlı ilerleme hesaplama (6236 ayet üzerinden)
  • Kur'an-ı Kerim görüntüleyici (Osmanlı Hattı)
  • Ayet işaretleme ve ilerleme kaydetme özelliği
  • Türkçe / Arapça dil desteği ve RTL/LTR düzeni

4.3 Kimlik Doğrulama Akışı

1. Kullanıcı Kaydı
Ad + E-posta + Şifre → bcrypt ile şifrelenir → SQLite'a kaydedilir
2. Giriş
E-posta + Şifre → bcrypt.compare → JWT token oluşturulur
3. API İstekleri
Token → Authorization header → Backend doğrular → Veri döndürür
4. Çıkış
LocalStorage temizlenir → Token geçersiz → Ana sayfaya yönlendirilir

6.1 API Endpoint'leri

6.2 Kimlik Doğrulama Middleware

Her yetkili endpoint'e gelen istek, JWT token kontrolünden geçmektedir. Token geçersizse 403 Forbidden hatası döndürülmektedir.

const authenticate = (req, res, next) => { const token = req.headers['authorization']; if (!token) return res.status(401).json({ error: 'Unauthorized' }); jwt.verify(token.split(' ')[1], SECRET, (err, decoded) => { if (err) return res.status(403).json({ error: 'Forbidden' }); req.userId = decoded.id; next(); }); };

6.3 Güvenlik Önlemleri

  • Şifre Güvenliği: Şifreler veritabanına bcrypt (salt round: 10) ile hashlenerek kaydedilmektedir. Düz metin şifre hiçbir zaman depolanmamaktadır.
  • JWT Token: Her oturum açma işleminde benzersiz bir token oluşturulmakta; token 24 saat sonra otomatik olarak geçersiz olmaktadır.
  • CORS: Yalnızca frontend kaynağından gelen istekler kabul edilmektedir.
  • Veri Doğrulama: Tüm endpoint'lerde gelen veriler kontrol edilmektedir.

8. Karşılaşılan Sorunlar ve Çözümleri

Sorun 1: Frontend-Backend CORS Hatası

⚠️ Sorun

React uygulaması (localhost:5173) Node.js sunucusuna (localhost:5000) istek gönderdiğinde tarayıcı CORS politikası hatası veriyordu. Tüm API çağrıları engelleniyor, konsolda Access-Control-Allow-Origin hatası görünüyordu.

✅ Çözüm

Backend'e cors npm paketi eklendi ve tüm kaynaklardan gelen isteklere izin verildi. Bu sayede frontend ve backend farklı portlarda çalışmasına rağmen başarıyla iletişim kurabilmektedir.

const cors = require('cors'); app.use(cors()); // Tüm origin'lere izin ver

Sorun 2: SQLite Modülü Kurulum Hatası

⚠️ Sorun

Windows üzerinde sqlite3 paketi kurulurken Native C++ binding derleme hatası oluştu. node-gyp kurulum başarısız oldu.

✅ Çözüm

Node.js'in LTS (Long-Term Support) sürümü kullanıldı ve sqlite3 paketinin ön derlenmiş (prebuilt) ikili dosyaları otomatik olarak indirildi. Ek araç kurulumuna gerek kalmadı.

Sorun 3: React'te import Sırası Hatası

⚠️ Sorun

App.jsx dosyasında useNavigate hook'u dosyanın ortasında import edilmeye çalışıldığında Vite derleme (build) hatası oluştu.

✅ Çözüm

Tüm import ifadeleri dosyanın en üstüne taşındı. React kurallarına göre import'lar her zaman dosyanın başında bulunmalıdır.

// ✓ Doğru - Dosyanın en üstünde import { BrowserRouter, Routes, Route, Navigate, Link, useNavigate } from 'react-router-dom';

Sorun 4: Giriş Başarısız - "Invalid credentials"

⚠️ Sorun

Kullanıcı giriş yapmaya çalıştığında "Invalid credentials" hatası aldı. Kullanıcılar sisteme giriş yapamıyordu çünkü henüz kayıt olmamışlardı.

✅ Çözüm

Veritabanı yeni oluşturulduğu için boştu. Kullanıcıya önce "Kayıt Ol" sayfasına gidip hesap oluşturması gerektiği açıklandı. Kullanıcı kayıt olduktan sonra giriş başarıyla gerçekleşti.

Sorun 5: Kur'an API Entegrasyonu

⚠️ Sorun

Tüm 6236 ayetin frontend uygulamasına dahil edilmesi durumunda JavaScript bundle boyutu 5MB'ı aşacaktı. Bu durum sayfa yükleme süresini olumsuz etkileyecekti.

✅ Çözüm

Harici ve ücretsiz bir API olan Alquran Cloud (api.alquran.cloud) entegre edildi. Uygulama yalnızca kullanıcı bir sure seçtiğinde o surenin verilerini API'den çekmektedir (lazy loading). Bu yaklaşım sayesinde ilk yükleme süresi minimum düzeyde tutulmaktadır.

// Sadece seçilen sure yüklendiğinde API çağrısı yapılır const res = await fetch( `https://api.alquran.cloud/v1/surah/${surahId}/quran-uthmani` );

9.2 Ekranların Açıklaması

Kayıt/Giriş Ekranı

Koyu (dark) arka planlı, modern bir tasarıma sahiptir. Kullanıcı adı, e-posta ve şifre alanlarından oluşmaktadır. Kayıt sayfası ile giriş sayfası arasında bağlantı mevcuttur.

Ana Panel (Dashboard)

İki ana bölümden oluşmaktadır:

  • Dahil Olduğunuz Hatimler: Kullanıcının kendi adına oluşturduğu hatimler
  • Diğer Hatimler: Başkası adına oluşturulan hatimler

Her hatim kartında şu bilgiler bulunmaktadır: Hatim adı, ilerleme yüzdesi, renkli ilerleme çubuğu, son durulan sure ve ayet, sure/ayet güncelleme dropdownları ve Kur'an okuma butonu.

Kur'an Okuyucu Sayfası

Üst kısımda hatim adı ve tamamlanma yüzdesi gösterilmektedir. Sure seçim menüsü ve gezinme butonları yer almaktadır. Ayetler Osmanlı hattıyla, sağdan sola (RTL) düzeninde büyük ve okunabilir bir şekilde sunulmaktadır. Kullanıcı herhangi bir ayete tıkladığında onay penceresi açılmaktadır.

10.1 Tamamlanan Özellikler

  • ✅ Full-Stack uygulama başarıyla geliştirildi (React + Node.js)

  • ✅ JWT tabanlı güvenli kimlik doğrulama

  • ✅ Türkçe/Arapça çok dilli destek ve RTL/LTR düzeni

10.4 Değerlendirme

Bu proje, modern web geliştirmenin temel kavramlarını kapsamlı bir şekilde uygulayan tam işlevli bir full-stack web uygulamasıdır. Frontend ve backend'in birbirinden bağımsız geliştirilmesi, REST API aracılığıyla iletişim kurması ve güvenli kimlik doğrulama mekanizmalarının kullanılması, projeyi gerçek dünya uygulamalarında kullanılabilecek standart bir mimari yapıya sahip kılmaktadır.

Kur'an-ı Kerim hatim takibi gibi manevi bir ihtiyacı teknoloji ile birleştiren bu uygulama, kullanıcıların okuma alışkanlıklarını dijital ortamda takip etmelerine önemli katkı sağlayacaktır.
